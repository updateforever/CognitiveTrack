# Qwen2.5-VL-7B v4.1 零样本能力探针（归档）

## 范围

2026-08-09 使用本地 `Qwen2.5-VL-7B-Instruct`、pair 双图上下文和
`qwen_abs_pixel` 坐标协议做了三次诊断性推理。这里只用于发现数据需求，不是
benchmark 结果；样本量不足以代表最终精度。

| 序列 / 帧 | GT | 模型输出摘要 | 结果 |
|---|---|---|---|
| `videoPlayer_video_09_done / 3` | present | present + 合法 bbox + `"no change"` | 解析与提交成功，bbox IoU 0.4256；no-op 记忆被本地门控拒绝 |
| `042 / 1215` | present，目标框完整 | absent + 移动位置记忆 | `absent + 非空记忆` 违反协议，记为 `parse_error` |
| `042 / 2883` | present，顶边局部可见 | absent + 摔倒/不可见记忆 | `absent + 非空记忆` 违反协议，记为 `parse_error` |

三次生成均给出了恰好三个 JSON 字段，说明基础格式跟随能力存在。普通帧即使明确
要求 JSON `null`，模型仍连续输出 `"no change"`；这不是继续堆 Prompt 就能可靠
解决的问题，应通过 SFT 学习更新开关。两个大时间跨度样本还暴露了目标存在判别
问题，尤其会把位置变化或局部可见误当成 absent。

## 对数据阶段的直接结论

1. 第一优先级仍是可靠的 `present/absent + bbox` 二字段数据，重点增采长间隔、
   局部可见、场景切换和同类干扰样本。
2. 记忆数据必须是独立的三字段版本，且包含大量规范 `memory_update=null` 负例；
   不能把现有无记忆标签样本直接补成 null。
3. 非空记忆只标注可从两帧直接核验的稳定外观、视角或构型变化，排除普通运动、
   尺度、模糊、消失描述和推理过程。
4. 数据划分继续按物理序列进行；同一变化事件附近的帧不能跨 train/val/test。
